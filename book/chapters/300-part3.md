# Part III: The Terminal {.part}

Part III gives each tab a live session: a child process on a
pseudo-terminal, read on the main loop without freezing the window. It then
builds a terminal-shaped widget from scratch, a character grid that scrolls,
takes keys and selects text, and finally swaps in gtkpyte, a real terminal
emulator with the same signals. Chapters 11 to 13 build a deliberately simple
widget so that Chapter 14 is wiring rather than a wall of new code.

Part III also contains the book's most consequential finding: the
recommended way to watch a file descriptor can stop a GTK window repainting,
and the fix is one argument.
