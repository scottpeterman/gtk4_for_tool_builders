# Part II: Building Tools {.part}

Part II turns the empty shell into a tool. It shows sessions in a list, then
in a filterable tree of folders; puts every command behind an action with a
menu entry and a keyboard shortcut; opens tabs that own their resources;
handles mouse and keyboard input in the right order; and adds context menus
and dialogs that do not block. Two checkpoints close it: a session browser,
and a tabbed window whose every shortcut is in a menu.

From Chapter 5 on, the window's state lives in a C++ class, `AppWindow`,
instead of in globals, and `main.cpp` shrinks to creating it.
